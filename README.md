# 어디살래?

**라이프스타일 분석 기반 지역 정착 매칭 서비스**

> **"여러분은 왜 서울에 오셨나요?"**
> 청년 20명에게 물었더니 70%가 "서울 말고는 잘모르고 정보도 없어서" 지방행을 생각하지 않았다고 답했습니다. 지자체는 세제 혜택, 정주여건 개선 등 다양한 정책을 시행해왔지만, 정작 청년들은 그 사실조차 모르고 실제 정착으로 이어지지 못하고 있습니다.       
> **문제는 지방이 아니라 정보 격차였습니다.** 저희는 이 격차를 해소할 서비스를 만들었습니다.

## 서비스 소개

MBTI처럼 가볍게 시작해서, 실제로 살아볼 수 있는 지역을 찾아주는 정착 성향 매칭 서비스입니다.

15개의 질문으로 라이프스타일을 진단하고, 전국 229개 시군구의 실측 공공데이터와 비교해 나에게 가장 잘 맞는 지역 Top 3를 추천합니다. 단순히 지역 정보를 나열하는 대신, AI가 왜 그 지역이 나와 맞는지 실제 답변을 근거로 설명해줍니다.

##  주요 기능

| 기능 | 설명 |
|---|---|
| **1분 정착 성향 테스트** | 15문항 A/B/C/D 4지선다로 6가지 정착 요소(주거비·교통·생활인프라·문화·자연환경·일자리) 진단 |
| **229개 지역 실측 매칭** | 월세·버스·문화시설·녹지 등 공공데이터 기반 6축 벡터와 가중 코사인 유사도로 비교 |
| **근거 기반 AI 리포트** | 실제 선택한 답변 문구를 인용해 "왜 이 지역인지" 구체적으로 설명 (환각 방지 설계) |
| **맞춤 정책 · 실시간 채용정보** | 지역 상세 페이지에서 온통청년 정책, 고용24 채용정보 실시간 조회 |

## 진단 → 매칭 → 결과 플로우

```
기본정보 입력 (예산·직무·자차·연령)
        +
15문항 응답 (A/B/C/D)
        ↓
   벡터화 · 가중치 적용
   (우선순위 2축 ×1.5, 자차 보유 시 교통축 ×0.3)
        ↓
   229개 지역 DB와 가중 코사인 유사도 비교
        ↓
   Top 3 지역 + AI 매칭 리포트 + 실시간 정책/채용 정보
```

## 기술 스택

**Frontend**
- React + TypeScript + Vite
- React Router

**데이터 파이프라인 / 매칭 엔진**
- Python (pandas, openpyxl) — 공공데이터 정규화 및 6축 벡터 구축
- TypeScript — 진단 벡터화, 필터링, 가중 코사인 유사도 매칭 로직

**외부 데이터 소스**
- 국토부 전월세 실거래가, 전국 버스정류소 표준데이터, 문체부 문화기반시설 통계, KOSIS 녹지환경 데이터
- 고용24 Open API (채용정보)
- 온통청년 Open API (청년정책)

## 폴더 구조

```
src/
├── pages/
│   ├── HomePage.tsx           # 랜딩 페이지
│   ├── ProfilePage.tsx        # 기본정보 입력
│   ├── TestPage.tsx           # 15문항 진단
│   ├── ResultPage.tsx         # 매칭 결과 + AI 리포트
│   └── RegionDetailPage.tsx   # 지역 상세 (채용·정책)
├── utils/
│   └── recommendation_engine.ts   # 벡터화 · 필터 · 매칭 · LLM 프롬프트 생성
├── data/
│   ├── regionData.ts          # 지역 벡터 로더
│   └── region_vectors_full.json  # 229개 시군구 × 6축 데이터
├── context/
│   └── UserContext.tsx        # 진단 응답 상태 관리
└── types/
    └── user.ts                # 사용자 프로필 타입 정의
```
